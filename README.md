# 电影推荐系统简介

## 项目概述

这是一个基于 Flask 框架开发的智能电影推荐系统，旨在为用户提供个性化的电影推荐服务。系统结合了协同过滤算法、用户画像分析和热门推荐等多种策略，能够根据用户的评分历史和偏好，精准地推荐符合用户口味的电影。

## 核心功能

### 1. 用户认证与管理
- 用户注册与登录
- 密码加密存储（使用 Werkzeug 安全哈希）
- 会话管理（支持"记住我"功能）
- 个人中心展示

### 2. 电影浏览与搜索
- 首页展示热门电影排行榜
- 支持按标题关键词搜索电影
- 支持按电影类型（Genre）筛选
- 分页浏览功能（每页40部电影）
- 自动识别多种分隔符的类型数据

### 3. 电影详情与互动
- 查看电影详细信息（标题、类型、平均评分、评分人数）
- 自动生成文艺风格的电影简介
- 用户对电影进行评分（0.5-5.0星）
- 发表影评评论（需先评分）
- 评论点赞功能
- 实时显示热门评论及用户评分

### 4. 智能推荐系统
系统采用三层推荐策略，确保推荐的多样性和准确性：

#### 策略A：基于用户的协同过滤（User-Based Collaborative Filtering）
- 寻找与当前用户有相似喜好的其他用户
- 推荐相似用户喜欢但当前用户未看过的电影
- 基于共同高分评价（≥4星）计算用户相似度

#### 策略B：基于用户画像的偏好推荐
- 分析用户历史高分评价的电影类型
- 提取用户偏好的前3种电影类型
- 推荐符合用户口味的高评分电影

#### 策略C：热门精选补充
- 基于全站评分数量和平均评分排序
- 推荐广受好评的热门电影
- 作为冷启动和结果补充策略

#### 冷启动处理
- 对于新用户（无评分记录），直接推荐全站热门电影
- 确保所有用户都能获得推荐内容

### 5. 数据可视化（个人中心）
- **全站评分分布柱状图**：展示全体用户的评分分布情况
- **个人口味雷达图**：可视化展示用户对不同电影类型的平均评分偏好
- 使用 Pyecharts 库生成交互式图表
- 统计评分总数、平均分等关键指标

## 技术架构

### 后端技术栈
- **Web框架**: Flask
- **数据库**: MySQL
- **用户认证**: Flask-Login
- **密码加密**: Werkzeug Security
- **数据可视化**: Pyecharts
- **数据处理**: Python collections.Counter

### 前端技术
- **模板引擎**: Jinja2
- **图表库**: ECharts (通过 Pyecharts 生成)
- **样式**: HTML + CSS

### 数据库设计
主要数据表：
- `users`: 用户信息表
- `movies`: 电影信息表（包含 movieId, title, genres）
- `ratings`: 评分记录表（userId, movieId, rating, timestamp）
- `movie_comments`: 电影评论表
- `comment_interactions`: 评论互动表（点赞记录）

## 算法效果

根据离线评估测试（80%/20% 训练集/测试集划分）：

| 指标 | 协同过滤 | 热门推荐基线 | 提升幅度 |
|-----|---------|-------------|---------|
| 精确率 | 10.27% | 3.47% | **+196.2%** |
| 召回率 | 6.03% | 2.46% | **+144.8%** |
| F1分数 | 0.0759 | 0.0288 | **+163.8%** |
| 多样性 | 18种类型 | 13种类型 | **+38.5%** |

**结论**: 协同过滤算法显著优于简单的热门推荐，在精确率、召回率和多样性方面均有大幅提升。

## 环境搭建与部署

### 1. 安装依赖

```bash
pip install flask flask-login mysql-connector-python werkzeug pyecharts sqlalchemy pandas
```

### 2. 初始化数据库

确保已安装 MySQL 并启动服务，然后执行：

```bash
# 步骤一：建库建表（创建5张数据表 + 索引）
mysql -u root -p < setup_database.sql

# 步骤二：导入电影和评分数据（约10万条评分记录）
python import_csv.py
```

或使用 MySQL 客户端工具（Navicat、MySQL Workbench 等）导入 `setup_database.sql` 文件。

### 3. 配置数据库连接

打开 `app.py`，修改数据库连接信息为你的本地配置：

```python
db_config = {
    'host': 'localhost',
    'user': 'root',
    'password': '你的MySQL密码',  # 替换为实际密码
    'database': 'movies_db'
}
```

### 4. 运行项目

```bash
python app.py
```

访问 http://127.0.0.1:5000 即可使用。
